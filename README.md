# ST Refit: Adventure

A new engine for Star Trek: 25th Anniversary. It runs the game from your own copy, reading the original files. Experimental: it also runs Star Trek: Judgment Rites.

Refit includes none of the game's files. You need your own copy of the game, from GOG, Steam or the original CD-ROM or floppy.

**Download** the latest version under [Releases](https://github.com/StarTrekRefit/adventure-refit/releases/latest). The Mac and Linux builds are untested.

- Discord (help, bug reports, ideas): https://discord.gg/M4CFYX2zGj
- ModDB: https://www.moddb.com/mods/star-trek-refit

The source code is not public.
