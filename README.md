# Star Trek Refit: Adventure

Downloads and updates for Star Trek Refit, a new engine for Star Trek: 25th Anniversary. Experimental: it also runs Star Trek: Judgment Rites.

Refit includes none of the game's files. You need your own copy of the game, from GOG, Steam or the original CD-ROM.

Downloads will appear under Releases on this page. The public beta, version 0.9, is not out yet.

Bug reports and feature requests go through the Discord server. The link will be posted here with the release.

The source code is not public.
